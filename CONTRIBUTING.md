# Contributing

Contributions, issues and ideas are welcome.

1. Fork the repo and create a branch: `git checkout -b feature/my-change`
2. Keep functions in `src/`, one function per file, with a help header (first comment block).
3. Add or update checks in `tests/run_tests.m` and make sure they pass: `addpath('tests'); run_tests`
4. Commit with a clear message and open a pull request describing what changed and why.

Ideas that fit well: new detectors (SIC, ML), more modulations, other correlation models, Octave support.
